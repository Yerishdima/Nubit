# Nubit vs vidIQ: что есть, что делаем, чего не будет

Источник по vidIQ — `docs/vidiq-research.md` (55 статей справки vidIQ + страницы тарифов, октябрь 2026).
Статусы: ✅ есть в Nubit · 🔜 в плане (очередь ниже) · 🔶 частично · ⛔ не делаем / невозможно без внешнего сервиса.

## Принципиальные отличия Nubit

| | vidIQ | Nubit |
|---|---|---|
| Оплата | подписка $19–49/мес + «кредиты» на ИИ (сгорают, не возвращаются) | бесплатно; платите только своему ИИ‑провайдеру за реальные запросы (по вашему ключу) |
| Данные | своя база за годы, серверы vidIQ | публичные данные YouTube + YouTube Data API (бесплатная квота) + ваша история, которая копится локально |
| ИИ | свои модели, «AI Coach» с пресетами; сам признаёт, что «может выдумывать и терять контекст» | Claude Opus 5.5 (или любой другой), который **сам** вызывает инструменты: поиск, видео, канал, субтитры, комментарии, подсказки |
| Формулы | закрыты, «directional» | открытые и воспроизводимые (VPH, outlier, вовлечённость, чек‑листы) |
| Лимиты | 3 результата / 3 конкурента / 3 идеи на Free | без лимитов |

## Очередь работ (по убыванию ценности)

1. График просмотров + лог смен названия/превью (из снимков) · Shorts‑карточка.
2. Единый Optimize‑score в Studio + эмоции/стили названий + 3 варианта описания с предпочтениями.
3. Симулятор выдачи: ваше превью и название среди реальных топ‑видео по запросу (Home / Search / Mobile, тёмная тема).
4. Ремикс, разбор комментариев, перевод, спорные слова, сценарий/план видео.
5. Поиск outliers с фильтрами; «Тренды по запросу»; CSV‑экспорт.
6. Публичный Channel Audit; оценка лучшего времени публикации по конкурентам.
7. Генерация превью через image‑API (OpenAI/Gemini) по ключу — опция.
8. Zero‑setup режим: встроенный в Chrome ИИ (Gemini Nano, Chrome 148+, без ключа) для простых задач.
9. YouTube Analytics (OAuth): ретеншн, watch time, подписчики, точное «лучшее время».
10. Clipping через ffmpeg + субтитры.
