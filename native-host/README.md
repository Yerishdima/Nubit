# Nubit native host (локальный помощник)

Небольшая программа на Node.js, через которую расширение Nubit может запускать
программы на вашем компьютере: `yt-dlp` (субтитры и метаданные), `ffmpeg` и любые
другие, которые вы укажете в настройках расширения.

Без помощника расширение полностью работает — просто без локальных программ.

## Установка (Windows)

1. Установите [Node.js LTS](https://nodejs.org) (если ещё нет).
2. Установите расширение (см. главный README) и откройте `chrome://extensions`.
   Включите «Режим разработчика» и скопируйте **ID** расширения Nubit
   (32 буквы). Этот же ID показывается в настройках расширения.
3. Запустите `install.bat` в этой папке и вставьте ID. Скрипт:
   - создаст `com.nubit.host.json` с путём к `host.bat`;
   - пропишет его в реестре для Chrome, Edge, Brave и Chromium (только текущий пользователь).
4. Перезагрузите расширение (кнопка ⟳ на `chrome://extensions`), откройте его
   настройки → «Проверить помощник».
5. В разделе «Локальный помощник» укажите пути к `yt-dlp.exe`, `ffmpeg.exe`
   (кнопка «Найти» ищет их в PATH).

Удалить: `uninstall.bat`.

## macOS / Linux

```sh
chmod +x install.sh host.sh
./install.sh <EXTENSION_ID>
```

## Что умеет помощник

| Команда      | Что делает                                                                 |
| ------------ | -------------------------------------------------------------------------- |
| `ping`       | Версия помощника, Node.js, ОС                                              |
| `which`      | Ищет программу в PATH                                                      |
| `exec`       | Запускает программу по абсолютному пути с аргументами (без shell), таймаут |
| `ytdlp_subs` | Скачивает субтитры через yt-dlp во временную папку и возвращает текст      |

Помощник запускает только то, что присылает расширение, а расширение присылает
только пути из ваших настроек. Подключиться к помощнику может только расширение
с ID из `com.nubit.host.json`. Журнал: `host.log` рядом с `host.js`.
