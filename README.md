# Nubit — ИИ-аналитик YouTube (расширение Chrome)

Nubit показывает аналитику прямо на YouTube (как vidIQ) и добавляет ИИ-помощника,
который видит открытую страницу, сам ищет данные и объясняет, **почему** видео
набирает просмотры и что с этим делать. Работает на ваших API-ключах, без подписки.

## Что умеет

**На странице видео** — карточка под плеером / в сайдбаре:
- просмотров в час (VPH) за всё время и «сейчас» (между вашими визитами);
- просмотры, лайки (%), комментарии (%), возраст, длительность, подписчики;
- **outlier** — во сколько раз видео обогнало медиану последних видео канала;
- SEO-оценка с чек-листом (название, описание, теги, главы, хэштеги…);
- скрытые теги (клик — копировать), языки субтитров;
- кнопки: «Анализ ИИ», «Почему так набирает?», «Варианты названий», «Теги и описание».

**В поиске, на главной и в рекомендациях** — значки на превью: просмотров в час
и outlier (×канала).

**ИИ-чат в боковой панели** (кнопка расширения или кнопки на карточке):
- видит открытое видео / поиск / канал (контекст прикрепляется к сообщению);
- сам вызывает инструменты: поиск YouTube, данные видео, последние видео канала,
  субтитры, комментарии, автоподсказки, анализ запроса (спрос/конкуренция);
- быстрые действия: разбор видео, причины роста, названия, теги и описание,
  анализ поискового запроса, разбор канала, конкуренты, идеи для видео, пересказ;
- стримит ответ, показывает, какие инструменты вызывает.

**Расширяемость через настройки:**
- ИИ-провайдер: **Claude** (рекомендуется), OpenAI, Gemini, Ollama (локально);
- ключ YouTube Data API (необязательно) — точная статистика, комментарии, поиск через API;
- **дополнительные API** — любой HTTP API с описанием, ИИ будет его вызывать;
- **программы на компьютере** (yt-dlp, ffmpeg и др.) через локальный помощник —
  укажите, где они лежат, и ИИ сможет их запускать (например, вытянуть субтитры).

## Установка расширения

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте, либо `git clone`.
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → выберите папку `extension/dist`.
4. Нажмите на иконку Nubit → ⚙ Настройки → вставьте ключ Claude
   (console.anthropic.com → API Keys) → «Проверить подключение» → «Сохранить».
5. Откройте любое видео на YouTube.

Готовая сборка лежит в `extension/dist`, собирать ничего не нужно.

### Ключ YouTube Data API (по желанию)

console.cloud.google.com → создать проект → APIs & Services → Library → включить
**YouTube Data API v3** → Credentials → Create credentials → API key. Бесплатная
квота 10 000 единиц в день (поиск стоит 100, остальное 1–3).

Без ключа расширение берёт публичные данные со страниц YouTube — всё работает,
кроме чтения комментариев через API (с открытой страницы комментарии читаются).

### Локальный помощник (yt-dlp, ffmpeg и другие программы)

См. [`native-host/README.md`](native-host/README.md): нужен Node.js, запускается
`native-host/install.bat`, затем в настройках указываются пути к программам.

## Как это устроено

```
extension/
  src/background/   service worker: ИИ-агент, инструменты, доступ к данным YouTube
    providers/      Claude (официальный SDK) и OpenAI-совместимый провайдер
    youtube.ts      Data API v3 или разбор ytInitialData/ytInitialPlayerResponse
    tools.ts        инструменты модели (поиск, видео, канал, субтитры, API, программы)
    agent.ts        цикл «модель → инструменты → модель»
  src/content/      скрипты на youtube.com: карточка, значки, контекст страницы
  src/sidepanel/    чат
  src/options/      настройки
  src/shared/       типы, метрики (VPH, outlier, SEO), i18n, markdown
  dist/             собранное расширение (загружается в Chrome)
native-host/        локальный помощник (Node.js) и установщик для Windows
```

Метрики: **VPH** = просмотры ÷ часы с публикации; **outlier** = просмотры ÷
медиана просмотров последних ~25 видео канала; **вовлечённость** = (лайки +
комментарии) ÷ просмотры. Оценки спроса/конкуренции по запросу — эвристика на
основе автоподсказок и топа выдачи (YouTube не публикует объём поиска).

Ключи хранятся в `chrome.storage.local` этого браузера и отправляются только
провайдеру, которому принадлежат.

## Разработка

```sh
cd extension
npm install
npm run build        # сборка в dist/
npm run typecheck
npm test             # юнит-тесты парсеров и метрик
xvfb-run node scripts/smoke.mjs   # smoke-тест в Chromium (Linux)
```
